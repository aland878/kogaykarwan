# UK Pizza & More — website

React + TypeScript + Vite + Tailwind CSS. Content comes from `../research/uk-pizza-and-more.md`.

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- Hero carousel: `src/components/Hero.tsx` (swap the `IMAGES` entries for your own photos)
- Menu, branches, contact details: `src/data.ts`
